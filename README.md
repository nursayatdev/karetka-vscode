# Каретка

Печатная машинка, которая запускает код. Пишешь программу на листе бумаги, нажимаешь **RUN**, и принтер печатает результат: текст, картинки, анимацию из цифр, видео или ошибку. Всё — в одном окне, как маленькая IDE.

> Проект личный и экспериментальный. Он запускает код на **вашем** компьютере с полными правами пользователя — см. раздел «Безопасность».

## Возможности

- **Лист бумаги в 3D (WebGL)** с физикой: бумага выходит из принтера и гнётся под собственным весом.
- **RUN / STOP**, вывод в реальном времени, выход кода, ошибки (включая подсказку `pip install` для недостающих модулей).
- **Python и JavaScript.** Для JS первой строкой ставится `// js`.
- **Картинки, видео, GIF и MP4** из вывода программы печатаются на бумаге. Кнопки TXT / PNG / MP4 / GIF сохраняют результат.
- **Машинка:** 5 моделей с собственными звуками, лента (чёрная/красная), «чистый» режим, казахская латиница (2021), жирный шрифт.
- **Проект:** открыть папку через системный диалог, дерево файлов, вкладки, редактор с подсветкой (Python, JS, JSON, HTML, CSS и др.), сохранение с проверкой внешних изменений, терминал (`cmd`/`sh`), «▶ Проект» с подсказками (`npm run dev`, `python main.py`…), удаление только в Корзину.
- **Запись демо:** `record-demo.js` записывает сценарий в MP4 со звуком.

## Быстрый старт (Windows)

Нужно: **Microsoft Edge** (есть в Windows), **Node.js 18+**. По желанию: **Python 3** (для `.py`), **ffmpeg** (для MP4/GIF из кадров).

1. Установите ярлык на рабочий стол (PowerShell, из папки проекта):
   ```powershell
   powershell -ExecutionPolicy Bypass -File .\install.ps1
   ```
   Появятся ярлыки «Каретка» и «Каретка — демо TikTok».
2. Откройте «Каретка». Ярлык запускает локальный сервер `server.js` (порт 47831) и открывает окно Edge.
3. Нажмите «Вставить лист» и печатайте.

Без сервера (открыв `index.html` напрямую) машинка работает, но RUN и проект недоступны.

### Запуск без ярлыка

```powershell
node server.js --port 47831
```
Затем откройте `http://127.0.0.1:47831/` в браузере.

## Как устроен RUN

1. `runner.js` собирает текст с листа (`getCode()`), учитывая мягкие переносы строк.
2. `POST /api/run` отправляет код на сервер. Сервер сохраняет его во временную папку и запускает `python -u` или `node`.
3. Вывод приходит потоком NDJSON (`out` / `err` / `end`).
4. Терминальный эмулятор (CSI H/J/K/A/B/C/D/G/s/u, цвета SGR, `\r`, `\f`) рисует результат. Очень широкий вывод (>100 символов) печатается мелкими цифрами, как картинка.
5. Кадры и изображения вставляются на WebGL-бумагу. Бумага выезжает из принтера, сохраняя физику изгиба.

Ограничения: 120 секунд на процесс, до 400 КБ кода, до 1200 КБ тела запроса.

## Безопасность

Сервер создан для локального использования, но код, который вы запускаете, работает с правами текущего пользователя.

- Слушает **только 127.0.0.1**.
- Проверяет заголовок `Host` (защита от DNS rebinding).
- Для `/api/*` и `/files/*` нужен случайный токен, который выдаётся **только** странице, которую отдаёт сервер (`window.KARETKA_API`).
- Для POST проверяется `Origin`.
- Статика отдаётся из белого списка файлов.
- Работа с папкой проекта ограничена этой папкой (проверка `path.relative` и реальных путей, защита от symlink).
- Удаление файлов — только в Корзину (`Microsoft.VisualBasic`).
- Терминал проекта выполняет любую команду, которую вы введёте. Не открывайте папки и не запускайте код, которому не доверяете.

## Разработка

- Фронтенд — обычный JavaScript без сборки. Скрипты подключаются в `index.html`: `runner.js`, затем `files.js`.
- Сервер — Node.js без зависимостей (`require` встроенных модулей).
- Тест вручную: откройте `demo.html?scene=...`, или запустите `record-demo.js --scene eye`.
- Мост между машинкой и принтером — `window.__K` (см. конец `index.html`). Не переименовывайте методы без правки `runner.js` и `files.js`.
- Перед коммитом проверяйте синтаксис: `node --check <файл>`.

### Внешние зависимости (не в репозитории)

- `vendor/py/` — `onnxruntime` (`pip install --target vendor/py onnxruntime`).
- `vendor/models/mobilenetv2-12.onnx` и `synset.txt` — модель MobileNetV2 из ONNX Model Zoo.

Без них пример `neural-cat` с распознаванием не запустится, остальное работает.

## Известные ограничения

- Звуки подобраны на слух, но не проверены на всех устройствах.
- Файл-панель и папку открывает системный диалог Windows (`FolderBrowserDialog`). На других ОС нужна правка `workspace.js`.
- Бумага и принтер рассчитаны на Chromium/Edge. В Safari WebGL-бумага может выглядеть иначе.
- Демо-сценарии печатают код медленно, потому что имитируют человека. Для скорости используйте `--speed`.
